隐私说明

更新日期：2026 年 9 月 9 日

1. 数据默认存在哪里

PAIA 默认把会话标题、消息、录音、照片、批次摘要和应用配置保存在 Android 应用私有目录。PAIA 发布者没有统一的云端会议数据库，也不会因为用户打开应用就自动收集这些内容。

2. 模型请求如何发送

当你主动使用实时转写、同声传译、问答或会议纪要时，应用会把对应内容发送到你在设置中填写的服务商接口，例如百炼或兼容的第三方接口。具体处理和保留期限由相应服务商的政策决定。

3. API Key 如何保存

API Key 只保存在本机的加密偏好存储中，不写入普通发布页面、会话导出内容或应用日志。请不要把 API Key 发布到 Gitee Issue、截图或公开仓库。

4. 权限用途

麦克风用于录音和语音识别，相机用于拍摄现场资料，通知权限用于显示录音和后台任务状态。你可以在系统设置中随时撤回权限；撤回后相应功能将不可用。

5. 删除和升级

在应用内删除会话时，应用会清理不再被其他会话引用的媒体文件。同包名、同签名的覆盖升级通常会保留本机数据；卸载应用可能会删除应用私有目录。

6. 联系方式

问题反馈请通过 PAIA 的 Gitee 仓库 Issue 提交。请只提供版本号、设备型号和复现步骤，不要上传会议原音频、照片或任何密钥。
