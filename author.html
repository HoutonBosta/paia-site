BEHIND PAIA

关于作者

多年追寻可自我迭代的 AI，目标始终如一。

研究方向与长期愿景

我是一名中国科学技术大学在读研究生，关注脑启发智能、持续学习、具身智能与组合泛化。这些研究共同指向一条核心主线：让 AI 研究 AI。

我的长期科研目标，是构建能够自主完成研发闭环的 AI：从提出问题、设计方案到实验验证与系统改进，让 AI 自主研发出比自身更强的下一代 AI，再由更强的系统继续研究与创造。通过这一轮又一轮的自我迭代，探索通向通用人工智能（AGI）的道路。这是我多年来持续追寻、始终未变的目标。

在这一研究目标之外，我也怀有一个社会愿景：期待高度发展的人工智能与自动化最终能够承担社会生产所需的全部劳动，使人们从生存压力下的劳动中解放出来，并让生产力进步的成果得到充分共享。我将这一关于技术、劳动解放与共同富裕的个人理想概括为“赛博共产主义”。

为什么开发 PAIA

开发 PAIA 的起点很简单：我自己迫切需要这样一个工具。在课堂、讲座和会议中，我希望既不错过关键信息，又能专注于理解；跟不上讲解时，能够立即提问、理清逻辑；结束后，还能用完整的录音与现场资料整理笔记、复习回顾。当时，我没有找到能够满足这些需求的现成产品，于是决定自己动手开发。

PAIA 是一个纯粹由内在需求驱动的项目，最初只是为了解决我自己的问题。将它公开发布，是希望在满足自身需求之余，也把这份成果分享给有相同需求的人，让它能够帮助更多人的学习与工作。

市场上已有不少类似产品与录音卡、录音笔或智能眼镜等专用硬件绑定。专用设备有各自的适用场景，但智能手机本身已具备麦克风、相机和联网能力。因此，我选择从这些已有能力出发，不以购买额外硬件为前提，让更多人能够用手边的设备获得智能辅助。

接下来的方向

我将持续探索让 PAIA 接入更多前沿模型，并计划为不熟悉 API Key 申请与配置的用户提供更便捷的托管模型接入，以及中转和代充值服务，让使用者可以在应用内完成开通与使用，同时保留自备 API Key 的选择。

上述托管、中转和代充值服务尚在规划中，暂未开放。具体服务方式、收费规则与隐私政策将在正式上线前公布。
