FAQ

开始前需要知道的事

安装 APK 会不会覆盖掉原来的会话？

使用同一 applicationId、同一正式签名并递增 versionCode 的 APK 覆盖安装，不会清除应用私有数据。不要先卸载旧版本。

为什么页面上暂时不能下载？

发布者需要先在 Gitee Release 上传 APK，再把附件地址和 SHA-256 写入 release.json。模板默认把按钮置为不可用，避免用户下载到错误文件。

没有 VPN 能下载吗？

国内发布页和下载附件建议放在 Gitee 或应用市场；GitHub 作为海外镜像。实际发布后请用手机关闭 VPN，分别测试 Wi-Fi 和移动数据。

遇到问题在哪里反馈？

请在 Gitee 仓库的 Issue 中附上版本号、设备型号和可复现步骤，不要提交 API Key、录音或照片。
