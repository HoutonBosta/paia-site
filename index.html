BEHIND PAIA

关于作者

从研究智能，到让智能成为日常学习与思考的助手。

研究方向与长期愿景

我目前在中国科学技术大学攻读研究生，关注脑启发智能、持续学习、具身智能与组合泛化。我的长期科研目标，是构建能够自主完成研发闭环的 AI：从提出问题、设计方案到实验验证与系统改进，研发出能力更强的下一代 AI，再由新的系统继续这一过程，通过反复迭代探索通向通用人工智能（AGI）的道路。

在这一研究目标之外，我也怀有一个社会愿景：期待高度发展的人工智能与自动化最终能够承担社会生产所需的全部劳动，使人们从生存压力下的劳动中解放出来，并让生产力进步的成果得到充分共享。我将这一关于技术、劳动解放与共同富裕的个人理想概括为“赛博共产主义”。

为什么开发 PAIA

PAIA 源于一个朴素的需求：在课堂、讲座和会议中，既不错过关键信息，也不因忙于记录而失去对内容的理解。它希望帮助使用者保存原始资料，在听到疑惑之处时快速提问，了解当前讨论的进度、理清逻辑脉络，并在结束后完成整理、复习与回顾。

市场上已有不少类似产品与录音卡、录音笔或智能眼镜等专用硬件绑定。专用设备有各自的适用场景，但智能手机本身已具备麦克风、相机和联网能力。PAIA 选择从这些已有能力出发，不以购买额外硬件为前提，让更多人能够用手边的设备获得智能辅助。

接下来的方向

PAIA 将持续探索接入更多前沿模型，并计划为不熟悉 API Key 申请与配置的用户提供更便捷的托管模型接入，以及中转和代充值服务，让使用者可以在应用内完成开通与使用，同时保留自备 API Key 的选择。

上述托管、中转和代充值服务尚在规划中，暂未开放。具体服务方式、收费规则与隐私政策将在正式上线前公布。

FAQ

开始前需要知道的事

安装 APK 会不会覆盖掉原来的会话？

使用同一 applicationId、同一正式签名并递增 versionCode 的 APK 覆盖安装，不会清除应用私有数据。不要先卸载旧版本。

这个版本适合日常使用吗？

这是公开测试版，使用 Android Debug 签名，适合体验和反馈问题。长时间录音、后台任务和不同设备兼容性仍可能存在问题，请不要在无法容忍数据丢失的场景中依赖它。正式版会使用长期保管的签名密钥。

没有 VPN 能下载吗？

国内发布页和下载附件建议放在 Gitee 或应用市场；GitHub 作为海外镜像。实际发布后请用手机关闭 VPN，分别测试 Wi-Fi 和移动数据。

遇到问题在哪里反馈？

请在 Gitee 仓库的 Issue 中附上版本号、设备型号和可复现步骤，不要提交 API Key、录音或照片。
